Avenir cannot be uploaded, ever. It is an Apple system font: free on iOS, and Apple's licence forbids redistribution. The web client substitutes Plus Jakarta Sans with Inter as fallback — which is what these previews render in. A "missing brand font" warning on this system is permanent, not a task.
Figma line heights sit below Bricolage's natural metrics on the tight headings. SwiftUI's lineSpacing can only add, never subtract, so those clamp to zero on iOS. True sub-natural line height needs a UIKit-backed label.
